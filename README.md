# OSS Shopping Cart 🛒

Welcome to the OSS Shopping Cart! This is a very simple, static shopping cart website built with purely HTML and CSS. 

This repository is designed specifically for **beginners** to learn how to contribute to Open Source Software (OSS) and practice raising Pull Requests (PRs).

## 🎯 Your First Task: Add a Product!

We want to expand our store's inventory. Your task is to add a new product to the website.

### How to contribute:

1. **Fork** this repository to your GitHub account using the "Fork" button at the top right.
2. **Clone** your forked repository to your local machine:
   ```bash
   git clone https://github.com/YOUR-USERNAME/oss-shopping-cart.git
   ```
3. **Open** `index.html` in your favorite text editor (like VS Code, Notepad, etc.).
4. **Find** the following comment in the code (around line 43):
   `<!-- NEW CONTRIBUTORS: Add your product HTML below this line! -->`
5. **Add** your new product using this HTML structure below the comment:
   ```html
   <div class="product-card">
       <div class="product-image">🍕</div>
       <h3>Your Product Name</h3>
       <p class="price">$10.00</p>
       <button class="add-to-cart">Add to Cart</button>
   </div>
   ```
   *(Feel free to use any emoji for the image, and make up a fun name and price!)*
6. **Save** the file.
7. **Test it** by double-clicking `index.html` to open it in your web browser. Make sure it looks good!
8. **Commit** your changes with a clear message:
   ```bash
   git add index.html
   git commit -m "Add [Your Product Name] to the store"
   ```
9. **Push** your changes to your fork:
   ```bash
   git push origin main
   ```
10. **Create a Pull Request (PR)** on the original repository!

## 🚀 Setup Instructions

Since this is just HTML and CSS, you don't need any complex setup like Node.js or Python!

1. Clone the repository.
2. Double-click `index.html` to open it in your web browser.
3. Start coding!

Happy hacking, and welcome to the world of Open Source! 🎉
