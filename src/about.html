What is this project?

The OSS Shopping Cart is a purely HTML and CSS project designed to help beginners make their first Open Source contributions. It demonstrates core layout concepts like Flexbox and CSS Grid while remaining approachable.

Check the README.md in the repository to learn how you can add your own product to our store!
